# 💕 Valentine's Day Romantic Website

A beautiful, interactive Valentine's Day website template with parallax scrolling, photo timeline, mini-game, and invitation reveal. Built with Next.js 14 and TypeScript.

**Perfect for creating a personalized romantic gift for your special someone!**

## ✨ Features

- **Romantic Hero Section** with floating tulip petal animations
- **Live Time Counter** showing days, hours, minutes, and seconds together
- **Parallax Photo Timeline** with smooth scroll effects
- **Interactive Tulip Catcher Game**
- **Beautiful Invitation Card**
- **Responsive Design**

## 🚀 Quick Start

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run development server**:
   ```bash
   npm run dev
   ```


## ⚙️ Configuration

Edit `src/config/loveConfig.ts` to customize names, dates, photos, and messages.
